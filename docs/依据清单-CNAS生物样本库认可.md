# CNAS 生物样本库认可申请资格自查工具 · 依据清单

> 规则库版本 v1.0.0 · 核定日期 2026-11-18
> 适用对象：医院生物样本库（人源样本为主）
> 本文件为规则库的编码依据留档，供复核与换版维护使用。

## 一、认可规范依据（已核实 CNAS 官网）

### 1. CNAS 官网「生物样本库认可」页面（权威口径）

来源：https://www.cnas.org.cn/zxfwpt/zxbl/sysxgjg/art/2024/art_93bb7f83c7044955978a81c5138d8bb7.html

**认可依据**（官网原文）：
- CNAS-CL10《生物样本库质量和能力认可准则》（等同采用 GB/T 37864）
- 其他相关认可规范文件

**申请条件**（官网原文，逐条）：
1. 基本了解 CNAS 的相关要求，且进行了有效的自我评估；
2. 具有明确的法律地位，其活动应符合国家法律法规的要求；
3. 建立了符合认可要求的管理体系，且正式、有效运行 **6 个月以上**；
4. 进行过完整的内审和管理评审，并能达到预期目的，且所有体系要素应有运行记录；
5. 技术能力满足 CNAS-RL02《能力验证规则》的要求；
6. 具有开展申请范围内的检测活动所需的足够资源，例如主要人员，包括授权签字人应能满足相关资格要求等；
7. 仪器设备的量值溯源应能满足 CNAS 相关要求；
8. 申请认可的技术能力有相应的检测经历，且经历应覆盖申请的全部项目/参数。

**申请材料**（官网原文）：
- CNAS-AL21《生物样本库质量和能力认可申请书》及附件（实验室/检验机构认可业务系统填写）
- CNAS-AL01-60《认可合同》及与机构申请范围相关的附表、附件

**收费依据**：认可委(秘)(2022)14 号《认可收费项目和标准（2022 版）》、CNAS-RL03《实验室和检验机构认可收费管理规则》。

### 2. CNAS-RL10《生物样本库认可规则》征求意见稿（2025）

来源：CNAS 官网附件（征求意见稿 PDF）

关键流程节点（征求意见稿口径，规则库已标注"按现行有效版本评估"）：
- 第 4 章 认可条件：明确法律地位、符合准则、遵守规范、保藏活动合法
- 第 5.1 条 初次认可：意向申请 → 正式申请和受理 → 文件评审 → 组建评审组 → 现场评审 → 评定发证
- 5.1.2.3：自第 1 次反馈问题起超过 **3 个月**仍不能满足受理条件的，不予受理
- 5.1.2.4：受理后一般 **3 个月**内安排评审；因申请人原因 3 个月内不能接受现场评审的，可终止认可过程
- 注：反馈期与评审安排时限在正式版中可能调整，交付前请核对现行文本

## 二、ISO 20387 / GB/T 37864 章节结构（已核实国标原文）

GB/T 37864-2019 使用翻译法等同采用 ISO 20387:2018，2020 年 CNAS-CL10:2020 等同采用该国标。

| 章 | 内容 | 关键条款 |
|---|---|---|
| 4 通用要求 | 4.1 总则 / 4.2 公正性 / 4.3 保密性 | 4.1.6 伦理规范、4.3 隐私与知情同意 |
| 5 结构要求 | 法人实体、最高管理层、管理机构 | 5.1 法人、5.7 活动范围形成文件、5.9 职责 |
| 6 资源要求 | 6.1 总则 / 6.2 人员 / 6.3 基础设施与环境 / 6.4 外部提供 / 6.5 设备 | 6.2 人员能力、6.4 供方、6.5 设备量值溯源 |
| 7 过程要求 | 7.1 总则 / 7.2 采集 / 7.3 接收分发 / 7.4 运输 / 7.5 可追溯性 / 7.6 制备保存 / 7.7 储存 / 7.8 质控 / 7.9 方法确认验证 / 7.10 信息数据管理 / 7.11 不符合输出 / 7.12 报告 / 7.13 投诉 | 7.5 唯一标识与溯源、7.9 方法验证、7.11 不符合 |
| 8 管理要求 | 8.1 方式 / 8.2 体系文件信息 / 8.3 文件控制 / 8.4 记录 / 8.5 风险防范 / 8.6 改进 / 8.7 纠正措施 / **8.8 内部审核** / **8.9 质量管理评审**（8.2-8.9 为方式 A） | 8.8 内审、8.9 管评 |

**重要**：网络上流传的部分"自查表"把内审标为 4.7、管评标为 4.8，与国标原文不符。本规则库按 GB/T 37864-2019 原文采用 **8.8 内审、8.9 管理评审**。

## 四、规则库设计

### 8 项硬门槛 → 题库映射

| CNAS 申请条件 | 对应题目 | 判定 |
|---|---|---|
| （一）自我评估 | self_assessment | gate: self_assessment |
| （二）法律地位 | legal_entity | gate: legal |
| （三）体系运行 6 个月 | qms_established, qms_runtime | gate: qms_runtime |
| （四）内审+管评+记录 | internal_audit, mgmt_review, records_complete | gate: audit_review |
| （五）能力验证 RL02 | proficiency_testing | gate: proficiency |
| （六）人员资源 | personnel, signatory | gate: personnel |
| （七）设备量值溯源 | equipment_traceability | gate: equipment |
| （八）技术经历覆盖 | technical_experience, scope_defined | gate: technical |

### 医院专项红线

human_samples=yes 时启用：ethics_approval（伦理）、informed_consent（知情同意）、hgr_compliance（人遗许可）。任一红线不通过 → 总判定 blocked。

### 总判定逻辑

- **blocked（暂不具备）**：存在红线，或三项核心硬门槛（法律地位/体系 6 个月/内审管评）任一未满足
- **conditional（补正后）**：无阻断项，但有其他门槛部分满足或未满足
- **ready（可申请）**：全部门槛满足

### 置信度分级

- A：认可准则/规则明文（CNAS-CL10、RL10、RL02、AL21、条例、细则、伦理办法）
- B：官方解答口径（本版暂未使用）
- C：实践惯例（明确标注，重大事项建议与 CNAS 或专业顾问确认）

## 五、已知边界与换版提示

1. CNAS-RL10 有 2025 修订征求意见稿，正式版发布后须复核流程时限（3 个月反馈期等）。
2. 本工具只判断"是否具备申请资格"，不判断"能否通过评审"，也不替代 CNAS 官方受理决定。
3. 适用范围限于科研用生物样本保藏；临床诊断用材料应走 ISO 15189 路径（工具已做提示）。
4. 认可费用标准（2022 版）未纳入规则库，申请前请核对 CNAS 官网最新收费。
