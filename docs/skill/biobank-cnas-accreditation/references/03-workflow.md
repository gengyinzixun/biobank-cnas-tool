# 03 · 认可咨询 7 阶段 SOP

> 与「ISO 20387 / CNAS 生物样本库认可咨询专家」工作流对齐，落地为中国口径可执行步骤。
> 每阶段写明：输入 → 动作 → 输出 → 判断标准（收口条件）。

## 总览

```
1 需求诊断 → 2 资格快判 → 3 差距分析 → 4 整改路线图
   → 5 文件体系建设 → 6 内审与管评辅导 → 7 评审前预检与持续改进
```

阶段 2 判定为「暂不具备」时，不进入阶段 3-7，直接输出整改路线图并约定复核时间；判定为「补正后可申请」时，阶段 3-7 与补正并行推进；判定为「可申请」时，重点转阶段 7 与申请材料准备。

## 阶段 1 · 需求诊断

- **输入**：客户初次问询。
- **动作**：按 `05-intake.md` 访谈提纲问清 6 项：机构类型、样本来源（人源/非人源）、申请范围、现有基础、目标时间节点、主要痛点。一次性最多问最关键的 3 项，避免问卷式轰炸。
- **输出**：机构画像 + 初步适用路径判断（ISO 20387 / ISO 15189 / 混合）。
- **收口标准**：能判断法律地位形态、是否涉及人源、是否涉及临床诊断用材料。

## 阶段 2 · 资格快判

- **输入**：22 题（非人源 19 题）答案。
- **动作**：运行 `scripts/eligibility_check.py`，或按 `02-eligibility.md` 逐条人工核对 8 项门槛 + 人源红线。
- **输出**：三档结论（可申请 / 补正后可申请 / 暂不具备）+ 8 项门槛核对表 + 红线核对 + P0/P1/P2 整改清单。
- **收口标准**：三档结论明确，每个非 met 项都有对应依据条款号与优先级。
- **注意**：结论为「是否具备申请资格」，不是「能否通过评审」，必须写进报告免责声明。

## 阶段 3 · 差距分析（Gap Analysis）

- **输入**：资格核对表 + 客户现有体系文件/记录清单。
- **动作**：按 CNAS-CL10 第 4-8 章逐条对照，按 `04-gap-analysis.md` 输出条款对照表。每条标注：符合 / 部分符合 / 不符合 + 差距描述 + 证据要求 + 依据条款号 + 置信度。
- **输出**：《差距分析报告》。
- **收口标准**：准则 4-8 章全部覆盖，无「待定」空行；每条不符合项都写明「怎么证明已做到」。

## 阶段 4 · 整改路线图

- **输入**：差距分析报告。
- **动作**：按优先级排序，每项写明根本原因、纠正措施、预防措施、验证方法、责任人、完成时限。
  - **P0**：合规红线与核心硬门槛（①③④、伦理/知情同意/人遗）——阻断申请，最先做。
  - **P1**：其余硬门槛（②⑤⑥⑦⑧）与评审高频不符合项（可追溯性、外部供方、生物安全、纠正措施）。
  - **P2**：一般项、优化项、文件措辞与格式。
- **输出**：《整改跟踪表》。
- **收口标准**：P0 项在提交申请前全部关闭并保留证据；区分强制「应/shall」与推荐「宜/should」。

## 阶段 5 · 文件体系建设

- **输入**：差距分析报告 + 申请范围。
- **动作**：搭建四级文件并用 `assets/` 模板起草：
  1. 质量手册（方针、目标、范围、组织与职责、体系要素映射）
  2. 程序文件（文件控制、记录控制、内审、管评、不符合控制、纠正措施、人员培训、设备管理、外部供方、样本全流程）
  3. SOP / 作业指导书（采集、接收、制备、冻存、复苏、分发、运输、质控、设备操作、LIMS 操作、应急预案）
  4. 记录表单（配套每一份程序与 SOP）

  SOP 一律按六段起草：**目的、范围、职责、程序、相关文件、记录**（见 `assets/SOP模板.md`）。
- **输出**：《体系文件清单》+ 全套文件草稿。
- **收口标准**：四级文件覆盖准则 4-8 章及申请范围内全部活动；每份 SOP 有配套记录表单；范围写明样本类型、来源与活动。

## 阶段 6 · 内审与管理评审辅导

- **输入**：运行满 6 个月的体系 + 全套文件。
- **动作**：
  - 内审（**8.8**）：策划内审方案 → 编制基于条款的检查表 → 内审员独立且经培训 → 覆盖全部范围与全部条款 → 开具真实不符合项 → 整改闭环并验证有效性 → 形成内审报告。
  - 管理评审（**8.9**）：最高管理者主持 → 输入含内审结果、投诉、风险、资源、质量目标、变更、能力验证结果 → 输出为决议与跟踪记录 → 形成管评报告。
- **输出**：内审方案/检查表/报告、管评输入清单/报告、不符合项整改闭环证据。
- **收口标准**：申请前完成至少一次完整内审和一次管评，不符合项全部关闭；「所有体系要素均有运行记录」。
- **注意**：内审流于形式、无真实不符合项，是评审高风险点；必须指导客户发现并关闭真实问题。

## 阶段 7 · 评审前预检与持续改进

- **输入**：完整体系 + 申请材料。
- **动作**：
  - 用 `assets/评审前核查清单.md` 做模拟评审：文件归档、现场布置、设备与温度记录、样本溯源抽查、人员应答演练。
  - 申请材料：CNAS「实验室/检验机构认可业务系统」线上填写 CNAS-AL21《生物样本库质量和能力认可申请书》及附件；签署 CNAS-AL01-60《认可合同》及申请范围相关附表附件。
  - 流程时限（RL10 征求意见稿口径，交付前核对现行文本）：自首次反馈问题起超过 3 个月仍不能满足受理条件的不予受理；受理后一般 3 个月内安排评审；因申请人原因 3 个月内不能接受现场评审的，可终止认可过程。
  - 获证后：监督评审准备、扩项认可、不符合项关闭、体系持续改进。
- **输出**：评审前核查结果、申请材料清单、应答要点卡。
- **收口标准**：核查清单无未关闭 P0/P1 项；申请材料真实、范围与体系一致。

## 阶段间通用纪律

- 每个交付物引用具体条款号，并标注置信度（A/B/C）。
- 区分机构类型（医院附属 / 科研院所 / 独立运营），法律地位与伦理归口不同。
- 涉及法规合规（人类遗传资源、医疗废物、生物安全）的问题，同时参考国家法规，并提示「以主管部门最新发布为准」。
- 客户名称、评审时间等项目事实不写入本技能，只存客户档案。
- 对外交付物统一署名「庚寅咨询 Gengyin Consulting · 青岛庚寅咨询服务有限公司」+ 免责声明。
