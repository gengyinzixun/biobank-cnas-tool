# 01 · 法规与认可规范依据（中国口径）

> 本文件是「生物样本库 CNAS 认可」咨询的唯一依据落点。任何答复、条款解读、交付物的条号与文件编号，均以本表为准；本表之外的编号须先核实再使用。

## 一、认可规范（已核实 CNAS 官网）

### 1. CNAS 官网「生物样本库认可」页面（权威口径）

来源：https://www.cnas.org.cn/zxfwpt/zxbl/sysxgjg/art/2024/art_93bb7f83c7044955978a81c5138d8bb7.html

**认可依据（官网原文）**：CNAS-CL10《生物样本库质量和能力认可准则》（等同采用 GB/T 37864）及其他相关认可规范文件。

**申请条件（官网原文，逐条，对应 8 项硬门槛）**：

1. 基本了解 CNAS 的相关要求，且进行了有效的自我评估；
2. 具有明确的法律地位，其活动应符合国家法律法规的要求；
3. 建立了符合认可要求的管理体系，且正式、有效运行 **6 个月以上**；
4. 进行过完整的内审和管理评审，并能达到预期目的，且所有体系要素应有运行记录；
5. 技术能力满足 CNAS-RL02《能力验证规则》的要求；
6. 具有开展申请范围内的检测活动所需的足够资源，例如主要人员，包括授权签字人应能满足相关资格要求等；
7. 仪器设备的量值溯源应能满足 CNAS 相关要求；
8. 申请认可的技术能力有相应的检测经历，且经历应覆盖申请的全部项目/参数。

**申请材料（官网原文）**：

- CNAS-AL21《生物样本库质量和能力认可申请书》及附件（实验室/检验机构认可业务系统填写）
- CNAS-AL01-60《认可合同》及与机构申请范围相关的附表、附件

**收费依据**：认可委(秘)(2022)14 号《认可收费项目和标准（2022 版）》、CNAS-RL03《实验室和检验机构认可收费管理规则》。具体金额交付前核对 CNAS 官网最新收费，不得凭记忆报价。

**CNAS-RL10 流程节点（征求意见稿口径，规则库已标注「按现行有效版本评估」）**：

- 第 4 章 认可条件：明确法律地位、符合准则、遵守规范、保藏活动合法。
- 第 5.1 条 初次认可：意向申请 → 正式申请和受理 → 文件评审 → 组建评审组 → 现场评审 → 评定发证。
- 5.1.2.3：自第 1 次反馈问题起超过 **3 个月**仍不能满足受理条件的，不予受理。
- 5.1.2.4：受理后一般 **3 个月**内安排评审；因申请人原因 3 个月内不能接受现场评审的，可终止认可过程。
- 注：反馈期与评审安排时限在正式版中可能调整，交付前请核对现行文本。

## 二、GB/T 37864-2019 / ISO 20387:2018 章节结构（已核实国标原文）

| 章 | 内容 | 关键条款 |
|---|---|---|
| 4 通用要求 | 4.1 总则 / 4.2 公正性 / 4.3 保密性 | 4.1.6 伦理规范、4.3 隐私与知情同意 |
| 5 结构要求 | 法人实体、最高管理层、管理机构 | 5.1 法人、5.6/5.7 活动范围形成文件、5.9 职责 |
| 6 资源要求 | 6.1 总则 / 6.2 人员 / 6.3 基础设施与环境 / 6.4 外部提供 / 6.5 设备 | 6.2 人员能力、6.4 供方、6.5 设备量值溯源 |
| 7 过程要求 | 7.1 总则 / 7.2 采集 / 7.3 接收分发 / 7.4 运输 / 7.5 可追溯性 / 7.6 制备保存 / 7.7 储存 / 7.8 质控 / 7.9 方法确认验证 / 7.10 信息数据管理 / 7.11 不符合输出 / 7.12 报告 / 7.13 投诉 | 7.5 唯一标识与溯源、7.9 方法验证、7.11 不符合 |
| 8 管理要求 | 8.1 方式 / 8.2 体系文件信息 / 8.3 文件控制 / 8.4 记录 / 8.5 风险防范 / 8.6 改进 / 8.7 纠正措施 / **8.8 内部审核** / **8.9 质量管理评审**（8.2-8.9 为方式 A） | 8.8 内审、8.9 管评 |

**重要纠错**：网络流传的部分「自查表」把内审标为 4.7、管评标为 4.8，与国标原文不符。一律采用 **8.8 内审、8.9 管理评审**。

**方式 A**：国内 CNAS 一般按质量管理体系方式 A 实施（8.2-8.9）。ISO 20387 附录 C 提供体系选项，涉外沟通时可说明，但对中国客户按方式 A 落地。

## 四、置信度分级（必须标注）

- **A 法规/准则明文**：CNAS-CL10、RL10、RL02、AL21、GB/T 37864、条例、实施细则、伦理审查办法、CNAS 官网申请条件原文。
- **B 官方解答口径**：CNAS 官方答复/说明文件。本版暂未纳入，遇到时补录并注明来源与日期。
- **C 实践惯例**：非规范性文件明文，系认可准备与评审实践中的通行做法（如四级文件分层、SPREC 记录、24h 温度监控、内审检查表设计）。必须显式标注，并附「重大事项建议与 CNAS 或专业顾问确认」。

## 五、已知边界与换版提示

1. CNAS-RL10 有 2025 修订征求意见稿，正式版发布后须复核流程时限（3 个月反馈期等）。
2. 本技能只判断「是否具备申请资格」与「如何准备」，不判断「能否通过评审」，不替代 CNAS 官方受理决定。
3. 适用范围限于科研用生物样本保藏；临床诊断用材料应走 ISO 15189 路径。
4. 认可费用标准（2022 版）未固化，申请前核对 CNAS 官网最新收费。
5. 准则中「应/shall」为强制、「宜/should」为推荐；整改资源按此排序。

## 六、口径红线（与旧资料的冲突处置）

部分旧专家资料或网络文章存在以下误标，答复时必须纠正，不得沿用：

| 误标 | 正确口径 |
|---|---|
| CNAS-CL06「生物样本库认可准则」 | **CNAS-CL10:2020** |
| CNAS-RL02「能力认可准则在生物样本库领域的应用说明」 | CNAS-RL02 是《**能力验证规则**》，非应用说明 |
| 内审 4.7 / 管评 4.8 | **内审 8.8 / 管理评审 8.9**（GB/T 37864-2019 原文） |
| 以 ISBER Best Practices / NCI / CAP / CLIA / GDPR 作为中国申请条件依据 | 仅可作术语与运营实践参考；中国申请条件以 CNAS 官网 8 条 + CL10/RL10 为准 |
