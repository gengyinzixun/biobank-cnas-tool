# 09 · 术语表（CNAS 生物样本库认可）

| 术语 | 定义 | 依据 |
|---|---|---|
| 法人实体 / 明确的法律地位 | 生物样本库应是法人实体，或法人实体的独立部分，能对其任何行为负法律责任；政府性质的样本库被认为是法人实体或与其地位相当的法人实体 | GB/T 37864 5.1；CNAS-RL10 第 4 章 |
| 生物样本库活动范围 | 样本库规定的活动范围应符合本标准并形成文件；样本库应声明仅其规定范围内的活动符合本标准，不包括外部提供的生物样本库活动 | GB/T 37864 5.6、5.7 |
| 质量管理体系（方式 A） | ISO 20387 附录 C 提供体系选项；国内 CNAS 一般按方式 A 实施：8.2 成文信息、8.3 文件控制、8.4 记录、8.5 风险防范、8.6 改进、8.7 纠正措施、8.8 内审、8.9 管评 | GB/T 37864 第 8 章、附录 C |
| 内部审核（内审） | 按策划的时间间隔进行，确定体系是否符合策划安排、本标准要求及样本库自身要求，是否有效实施和保持；内审员独立、经培训，覆盖全部范围与条款 | **GB/T 37864 8.8** |
| 质量管理评审（管评） | 最高管理者按策划间隔评审体系适宜性、充分性、有效性；输入含内审结果、投诉、风险、资源、质量目标、变更；输出为决议与跟踪记录 | **GB/T 37864 8.9** |
| 人员能力要求 | 配备专/兼职人员，有权限与资源实施、保持、监控、改进体系；识别偏离、评估影响、制定措施、向管理层报告；经培训、能力评估与授权并保存记录 | GB/T 37864 5.9、6.2 |
| 设备与量值溯源 | 配备采集/处理/储存/转运所需设备，建立台账、校准、维护与验证程序；关键设备使用前确认性能；温度等关键参数持续监控 | GB/T 37864 6.5；申请条件（七） |
| 能力验证 | 按申请范围参加相应能力验证或实验室间比对，频次与覆盖领域满足 CNAS-RL02 要求 | CNAS-RL02；申请条件（五） |
| 可追溯性 / 信息和数据管理 | 样本及相关数据应可追溯，样本有唯一标识并能在全生命周期追溯；电子记录防篡改、权限分级、定期备份，保护供体隐私 | GB/T 37864 7.5、7.10 |
| 不符合输出 | 识别并控制不符合的过程/输出，处置不符合样本，必要时通知相关方 | GB/T 37864 7.11 |
| 纠正措施 | 分析不符合根本原因、制定并实施纠正措施、验证有效性 | GB/T 37864 8.7 |
| 外部提供的过程、产品和服务 | 冷链运输、耗材试剂、检测、校准、维保等，应评价、准入、监控与再评价，合同明确质量要求 | GB/T 37864 6.4 |
| 伦理审查与知情同意 | 遵守样本及相关数据的区域、国家、国际伦理规范；保护供体、接收者与用户隐私和权利，仅在协议/授权下发布样本与数据 | GB/T 37864 4.1.6、4.3；《伦理审查办法》（2023） |
| 人类遗传资源保藏行政许可 | 在我国境内以科研为目的、为科研提供基础平台而长期保存人类遗传资源，须经主管部门批准取得保藏许可；临床诊疗/教学为主兼顾科研、已上市药械生产目的、检测后临时存储等不构成保藏 | 《人遗条例》第十四条；《实施细则》（2026，卫健委令第16号）第 21、22 条 |
| SPREC | Standard PREanalytical Code，用紧凑编码记录样本类型、采集管、处理时限、储存条件等前处理变量，便于下游判断样本适用性 | 实践惯例（置信度 C），非准则强制 |
| 冷缺血时间 | 组织离体至固定/冷冻的时间，是影响样本质量的关键前分析变量 | 实践惯例（置信度 C） |
| 冻融次数 | 样本反复冻融会降解蛋白、RNA 与代谢物，通常限制 1-2 次；宜采用小体积多分装策略 | 实践惯例（置信度 C） |
| 四级文件 | 质量手册 / 程序文件 / SOP 作业指导书 / 记录表单 | 实践惯例（置信度 C） |
| 三级/P0-P1-P2 优先级 | P0 红线与核心硬门槛（阻断申请）；P1 其余硬门槛与评审高频不符合项；P2 一般与优化项 | 本技能规则库约定 |
| 三档结论 | 可申请 ready / 补正后可申请 conditional / 暂不具备 blocked | 本技能规则库约定 |
| 置信度 A/B/C | A 法规准则明文；B 官方解答口径；C 实践惯例 | 本技能规则库约定 |
