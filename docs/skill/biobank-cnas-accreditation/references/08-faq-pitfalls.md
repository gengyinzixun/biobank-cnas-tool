# 08 · 高频误区、口径红线与常见问答

## 一、必须纠正的硬错误（答复前自检）

| # | 常见错误说法 | 正确口径 | 后果 |
|---|---|---|---|
| 1 | 「生物样本库认可准则是 CNAS-CL06」 | **CNAS-CL10:2020**《生物样本库质量和能力认可准则》 | 准则编号错，整份报告不可信 |
| 2 | 「CNAS-RL02 是能力认可准则在生物样本库领域的应用说明」 | CNAS-RL02 是《**能力验证规则**》，申请条件第（五）项引用其频次与覆盖要求 | 能力验证要求无从落地 |
| 3 | 「内审在 4.7 条、管理评审在 4.8 条」 | **内审 8.8、管理评审 8.9**（GB/T 37864-2019 原文，方式 A）；网传自查表误标 | 内审管评辅导依据错误 |
| 4 | 「体系运行 3 个月就能申请」 | 申请条件（三）硬性要求正式、有效运行 **6 个月以上**，且有完整运行记录 | 受理阶段直接不予受理 |
| 5 | 「只要写了体系文件就算建立体系」 | 「有效运行」须有真实样本、真实记录；纸面体系/空库不满足 | 现场评审重大不符合 |
| 6 | 「ISBER / NCI Best Practices / CAP / CLIA 是中国 CNAS 认可依据」 | 仅可作术语与运营实践参考；中国申请条件以 CNAS 官网 8 条 + CL10/RL10 为准 | 口径错位，客户按要求准备却不符合国内受理 |
| 7 | 「GDPR / 德国 BGB 的广泛同意规则可直接套用」 | 中国适用《伦理审查办法》《人遗条例》及 2026 年《实施细则》 | 合规建议无效甚至误导 |
| 8 | 「样本库认可 = ISO 15189 医学实验室认可」 | 科研用样本保藏走 CNAS-CL10；临床诊断用材料走 ISO 15189；混合须区分范围 | 走错认可路径 |
| 9 | 「人遗保藏一律要办许可证」 | 2026 版《实施细则》已收窄保藏定义；临床诊疗/教学为主兼顾科研的样本保存**不构成保藏** | 误办许可、浪费成本 |
| 10 | 「能力验证随便参加一次即可」 | 须按申请范围参加相应能力验证或实验室间比对，**频次与覆盖领域**满足 RL02 | 文审/受理不符合 |

## 二、口径红线（每次答复自检）

1. 条号、文件编号、版本号、收费金额一律查 `01-basis.md`，不凭记忆。
2. 置信度分级 A / B / C；实践惯例（C）必须标注并提示与 CNAS 确认。
3. 区分强制「应/shall」与推荐「宜/should」。
4. 区分机构类型（医院附属 / 科研院所 / 独立运营 / 企业）。
5. 整改方案必写「怎么证明已做到」。
6. 只判「申请资格」与「如何准备」，不判「能否通过评审」，附免责声明。
7. 客户事实不写入本技能，只存客户档案。
8. 换版提示：RL10 有 2025 征求意见稿；人遗细则 2026-11-11 换版无过渡期。

## 三、常见问答

**Q：体系刚建 2 个月，能先提交申请边运行边补吗？**
A：不能。申请条件（三）为硬性 6 个月以上且有效运行。建议按整改路线图倒排：先补齐文件与记录、启动运行，满 6 个月并完成一次完整内审与管评后再提交。

**Q：内审发现了不符合项，没关闭完能申请吗？**
A：申请条件（四）要求内审和管评「能达到预期目的」，且所有体系要素有运行记录。不符合项未关闭通常判定为部分满足，属「补正后可申请」；建议全部关闭并验证有效性再提交。

**Q：授权签字人一定要有吗？**
A：申请条件（六）特别指出「包括授权签字人应能满足相关资格要求」。若申请范围涉及对外分发与报告签发，此项必查；不涉及报告签发的可判为 na。

**Q：我们只存科研样本，冰箱很全，还需要 LIMS 吗？**
A：准则 7.5、7.10 要求唯一标识与全生命周期可追溯、信息和数据受控。纸质台账在规模小时可用等效系统，但「记录碎片化、无法完整追溯」是行业最常见短板，也是评审高频不符合项。建议至少做到唯一标识 + 全流程记录 + 权限分级 + 定期备份。

**Q：医院样本库既有临床剩余样本又有科研样本，怎么定范围？**
A：在范围文件中明确区分两类样本的流程、储存区域、记录与适用标准。临床诊断用材料优先考虑 ISO 15189 路径；科研保藏部分按 CNAS-CL10 申请，避免范围混同导致评审缩减。

**Q：人遗保藏许可到底要不要办？**
A：按 2026 年卫健委令第 16 号，以科研为目的长期保藏需许可；临床诊疗/教学为主兼顾科研、已上市药械生产目的、检测后临时存储等不构成保藏。涉及重要遗传家系、特定地区、大规模采集（>10000 例）另判采集许可。不凭印象判定，先用人遗申报备案评估工具做路径初判。

**Q：能力验证（RL02）具体怎么算满足？**
A：按申请范围参加相应能力验证或实验室间比对，频次与覆盖领域满足 RL02 要求；未开展或覆盖不足是常见不予受理/评审不符合项。不确定时按申请范围逐项对照 RL02 核对，或提示客户向 CNAS 确认。

**Q：不予受理后多久能再申请？**
A：因资料不真实等原因不予受理的，36 个月内不再接受申请；因管理体系问题不予受理的，6 个月后才能再次提交（口径见 `06-onsite.md`，交付前核对现行 RL10 文本）。

**Q：认可要花多少钱、多久拿证？**
A：收费依据为认可委(秘)(2022)14 号与 CNAS-RL03，具体金额核对 CNAS 官网最新收费，不凭记忆报价。时间取决于体系运行时长（硬性 6 个月）、整改进度与评审排期（受理后一般 3 个月内安排评审），不承诺获证时间。

## 四、与国外资料的关系（可作参考，不可作依据）

GitHub 上的 `sample-biobanking`、`managing-biospecimen-protocols` 等英文 Skill 内容覆盖 ISBER / NCI Best Practices / CAP / CLIA / ICH-GCP / GDPR，可作为以下用途的参考：SPREC 前处理编码、冷链与断电预案、样本分装策略、监管链设计、MTA/成本回收、QC 指标设计。

但**不得**作为：认可申请条件依据、条款号来源、伦理与知情同意的法定要求、人遗合规判断依据。凡涉及中国认可与合规结论，一律回到 `01-basis.md`。
