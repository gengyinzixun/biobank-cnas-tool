# 02 · 申请资格：8 项硬门槛 + 人源红线 + 三档判定

> 规则库 v1.0.0 · 与 `scripts/eligibility_check.py` 判定逻辑一致
> 依据：CNAS 官网「生物样本库认可」8 项申请条件原文 + CNAS-CL10 / RL10 / RL02。

## 一、8 项硬门槛逐条判定

| # | 门槛 | 满足条件 | 部分满足 | 不满足 | 依据 | 优先级 |
|---|---|---|---|---|---|---|
| ① | 明确的法律地位 | 独立法人，或法人授权的独立运行部门（有正式授权文件） | 法律地位需进一步判定 | 无独立法律地位、也无授权 | RL10 第 4 章；GB/T 37864 第 5.1 条 | **P0** |
| ② | 有效的自我评估 | 已完成覆盖准则 4-8 章的书面自查报告与不符合项清单 | 做了部分、未形成完整报告 | 尚未开展 | RL10 第 6 章；实践惯例 C | P1 |
| ③ | 体系建立且有效运行 ≥6 个月 | 正式有效运行 6 个月以上，且有完整运行记录 | 运行不足 6 个月 | 文件写了未运行/空库/尚未运行 | 申请条件（三）；GB/T 37864 第 8 章 | **P0** |
| ④ | 完整内审 + 管理评审 + 运行记录 | 内审完成且不符合项整改闭环 + 管评完成有报告 + 全要素记录完整 | 内审有未关闭项 / 管评已计划未实施 / 记录部分缺失 | 未开展 | 申请条件（四）；**8.8 内审、8.9 管评** | **P0** |
| ⑤ | 能力验证满足 CNAS-RL02 | 已按 RL02 参加，频次与覆盖满足 | 参加过但频次/覆盖不足；或不确定如何判断 | 尚未参加 | 申请条件（五）；RL02 | P1 |
| ⑥ | 足够资源（人员/授权签字人） | 关键岗位齐全且完成能力确认；授权签字人满足资格或不涉及报告签发 | 人员基本到位但档案/授权不全；签字人已指定材料待补 | 关键岗位缺失/签字人未确定 | 申请条件（六）；5.9、6.2 | P1 |
| ⑦ | 仪器设备量值溯源 | 台账/校准验证/24h 温度监控/报警/应急预案齐全 | 部分设备有校准，监控或记录不全 | 基本没有量值溯源与监控 | 申请条件（七）；6.5、7.7 | P1 |
| ⑧ | 技术经历覆盖全部申请范围 | 全部项目/参数均有真实经历与记录 + 范围已明确形成文件 | 主要项目有部分缺失 / 范围未逐项写明 | 多数项目无真实经历 | 申请条件（八）；5.7、7.9 | P1 |

## 二、人源样本 3 条红线（仅当保藏人源样本时启用）

非人源样本（动物、植物、微生物）不适用，判定为 na。

| 红线 | 满足 | 阻断 | 依据 | 优先级 |
|---|---|---|---|---|
| 🚫 伦理审查 | 已取得覆盖保藏与使用的有效伦理批件 | 批件未覆盖全部范围，或未通过伦理审查 → **一票否决** | 《涉及人的生命科学和医学研究伦理审查办法》（2023）；CL10 第 4.1.6 条 | **P0** |
| 🚫 知情同意 | 完整、版本受控、覆盖保藏与后续使用 | 不完整 / 版本不清 → 评审必查项 | 伦理审查办法；GB/T 37864 第 4.3 条 | **P0** |
| 🚫 人类遗传资源合规 | 已取得保藏许可/完成备案，或经判定不构成保藏 | 申请中 / 应办未办 → 红线；不确定 → 先做人遗路径初判 | 《人遗条例》第十四条；《实施细则》（2026，卫健委令第16号）第二十一、二十二条 | **P0** |

详见 `07-hgr-redline.md`。

## 三、总判定逻辑

```
hasRedline = 任一红线状态为 redline
hardGates  = { ① legal, ③ qms_runtime, ④ audit_review }
hardUnmet  = hardGates 中任一为 unmet
anyUnmet   = 任一门槛为 unmet
anyPartial = 任一门槛为 partial

if (hasRedline || hardUnmet)        → blocked   暂不具备申请条件
else if (anyUnmet || anyPartial)    → conditional 补正后可申请
else                                → ready     可申请
```

结论口径：

- **可申请**：8 项申请条件均已满足，且未发现合规红线，可以按流程准备材料并提交 CNAS 认可申请。
- **补正后可申请**：核心条件基本具备，但有 N 项待补正。完成整改并保留运行记录后再提交申请，可显著提高受理与文审通过率。
- **暂不具备申请条件**：存在 N 项阻断性问题（含硬性门槛未满足或合规红线），建议先完成整改，暂不提交申请。

整改清单按 P0 → P1 → P2 排序，仅列出非 met、非 na 的项。

### 风险提示（blocked 时必附）

CNAS 对资料不实、体系未有效运行、人源样本合规缺失的申请不予受理；因资料不真实等原因不予受理的，36 个月内不再接受申请；因管理体系问题不予受理的，6 个月后才能再次提交。

## 四、22 题四层自查题库

四层漏斗：第 1 层主体与法律地位 → 第 2 层管理体系运行 → 第 3 层资源与技术能力 → 第 4 层人源样本合规。非人源样本跳过第 4 层 3 题，共 19 题。

### 第 1 层 · 主体与法律地位

| id | 题目 | 选项（value → label） |
|---|---|---|
| legal_entity | 申请主体的法律地位是否满足要求？ | independent 独立法人 / authorized 法人授权独立运行部门 / none 无独立法律地位也无授权 / unclear 不确定 |
| self_assessment | 是否已对照 CNAS-CL10 完成有效的自我评估？ | yes 已完成书面报告与不符合项清单 / partial 做了部分 / no 尚未开展 |
| scope_defined | 申请认可的范围是否已明确界定并形成文件？ | yes 已明确样本类型+活动范围 / partial 大致范围未逐项写明 / no 尚未界定 |
| scope_clinical | 拟申请范围是否涉及临床诊断或治疗用生物材料？ | no 仅科研用 / yes 涉及 / mixed 两者都有已区分 / unclear 不确定 |

> 范围须写明样本类型（全血、组织、细胞、核酸等）、来源（人源/动物/微生物）与开展的活动。范围过大而无 SOP 与验证支持，评审时会被缩减。（5.7 条）

### 第 2 层 · 管理体系运行

| id | 题目 | 选项 |
|---|---|---|
| qms_established | 是否已建立符合 CNAS-CL10 的管理体系文件？ | yes 四级文件齐全覆盖全部范围 / partial 有手册和部分程序 / no 尚未建立 |
| qms_runtime | 管理体系正式、有效运行了多久？ | ge6m 6 个月以上且有完整记录 / lt6m 不足 6 个月 / paper 文件写了未运行/空库 / no 尚未运行 |
| internal_audit | 是否完成过完整的内部审核？ | yes_closed 已完成且整改闭环 / yes_open 已做但有未关闭项 / partial 部分要素 / no 未开展 |
| mgmt_review | 是否完成过管理评审？ | yes 已完成有报告与决议跟踪 / planned 已计划未实施 / no 未开展 |
| records_complete | 所有体系要素是否都有真实、可追溯的运行记录？ | yes 完整可追溯 / partial 部分缺失 / no 零散/基本没有 |
| corrective_action | 是否建立了不符合控制与纠正措施机制？ | yes 已建立并有闭环记录 / partial 有流程执行记录不全 / no 尚未建立 |

> 「有效运行」意味着有真实样本、真实记录，不是纸面体系或空库。内审员应独立、经培训，覆盖全部范围与条款（8.8）。管评输入应含内审结果、投诉、风险、资源、质量目标、变更（8.9）。

### 第 3 层 · 资源与技术能力

| id | 题目 | 选项 |
|---|---|---|
| personnel | 关键岗位人员是否配齐并完成能力确认？ | yes 齐全且档案完整 / partial 到位但档案授权不全 / no 缺失 |
| signatory | 授权签字人是否满足资格要求？ | yes 已确定满足 / partial 已指定材料待补 / na 不涉及报告签发 / no 尚未确定 |
| equipment_traceability | 仪器设备的量值溯源与监控是否满足要求？ | yes 台账/校准/24h监控/报警/应急预案齐全 / partial 监控或记录不全 / no 基本没有 |
| proficiency_testing | 能力验证频次与覆盖是否满足 CNAS-RL02？ | yes 已按 RL02 参加满足 / partial 频次或覆盖不足 / no 尚未参加 / unclear 不确定如何判断 |
| technical_experience | 申请认可的每项技术能力是否都有相应真实经历？ | yes 全部项目均有经历与记录 / partial 主要项目有部分缺失 / no 多数无真实经历 |
| external_providers | 外部提供的过程、产品和服务是否已评价并受控？ | yes 已评价准入并保留监控记录 / partial 评价记录不全 / no 未评价无控制 / na 无外部供方 |
| lims_traceability | 样本全生命周期是否可追溯（LIMS 或等效系统）？ | yes 唯一标识+全流程溯源+权限备份 / partial 有台账溯源链不完整 / no 无法完整追溯 |

> 关键设备（超低温冰箱、液氮罐、离心机、移液器）须台账、确认/验证、校准、维护、故障记录；温度 24h 连续自动监控并有报警与处置记录；配备备用电源与备用存储（6.5、7.7）。仅有低温冰箱而无 LIMS/完整溯源是行业最常见短板（7.5、7.10）。

### 第 4 层 · 人源样本合规红线（human_samples=yes 时启用）

| id | 题目 | 选项 |
|---|---|---|
| human_samples | 样本库是否保藏人源样本？ | yes 是 / no 仅非人源 |
| ethics_approval | 人源样本采集、保藏与使用是否通过伦理审查？ | yes 已取得有效批件覆盖保藏与使用 / partial 部分项目有未覆盖全部 / no 未通过 |
| informed_consent | 知情同意体系是否完整、版本受控？ | yes 完整版本受控覆盖保藏使用 / partial 版本或范围不清 / no 不完整/未取得 |
| hgr_compliance | 人类遗传资源保藏许可/备案是否已完成？ | yes 已取得许可/备案或经判定不构成保藏 / pending 申请中/未取得 / no 应办未办 / unclear 不确定是否需要 |
| biosafety | 生物安全与应急预案是否满足要求？ | yes 生物安全+应急预案+灾难恢复齐全 / partial 有部分制度预案不全 / no 尚未建立 |

> 三项红线（伦理、知情同意、人遗）任一不通过 → 总判定 blocked。生物安全为过程控制补充项，不参与资格阻断，但属评审高频不符合项。

## 五、过程控制补充结论（不参与资格判定，作为提示）

当 lims_traceability / external_providers / biosafety / corrective_action 任一为 no 或 partial 时，输出「评审高频不符合项：过程控制短板」提示：

- 样本唯一标识与全生命周期溯源不完整（7.5、7.10）
- 外部供方评价与受控不足（6.4）
- 生物安全与应急预案不全（4.1.1、8.5）
- 不符合控制与纠正措施机制不健全（8.7、7.11）

依据与整改要求见 `04-gap-analysis.md`。

## 六、适用范围提示

当 scope_clinical = yes 或 mixed 时，输出：ISO 20387 / GB/T 37864 适用于科研用生物样本保藏，不直接适用于临床诊断或治疗制剂用材料；若样本直接用于临床诊断，应优先考虑 ISO 15189（医学实验室认可）路径；混合场景建议在体系中明确区分两者流程与适用标准，避免范围混同导致评审缩减。
