# 06 · 申请材料、认可流程、现场评审与整改闭环

## 一、申请材料（CNAS 官网原文）

通过 CNAS「实验室/检验机构认可业务系统」线上提交：

| 材料 | 说明 |
|---|---|
| CNAS-AL21《生物样本库质量和能力认可申请书》及附件 | 线上填写，对材料真实性负责 |
| CNAS-AL01-60《认可合同》及与申请范围相关的附表、附件 | 签署并明确申请范围 |

配套必备证据（申请前须齐备）：

- 法人证书或法人授权文件、组织结构图
- 质量手册、程序文件、SOP、记录表单四级文件清单
- 体系有效运行 ≥6 个月的完整运行记录
- 完整内审报告（含不符合项整改闭环证据）与管理评审报告
- 能力验证/实验室间比对参加记录（CNAS-RL02）
- 人员台账、培训与授权记录、授权签字人资格材料
- 设备台账、校准/验证证书与确认记录、温度监控记录
- 申请范围内每项技术能力的真实经历记录与方法确认/验证证据
- 伦理批件、知情同意书版本、人遗保藏许可或「不构成保藏」判定依据（人源样本时）

收费依据：认可委(秘)(2022)14 号《认可收费项目和标准（2022 版）》、CNAS-RL03。具体金额核对 CNAS 官网最新收费，不得凭记忆报价。

## 二、认可流程与时限（RL10 征求意见稿口径，交付前核对现行文本）

```
意向申请 → 正式申请和受理 → 文件评审 → 组建评审组 → 现场评审 → 评定发证
```

关键时限：

- 自第 1 次反馈问题起超过 **3 个月**仍不能满足受理条件的，不予受理。
- 受理后一般 **3 个月**内安排评审。
- 因申请人原因 3 个月内不能接受现场评审的，可终止认可过程。

不予受理后果（blocked 场景必须提示）：

- 因资料不真实等原因不予受理的，**36 个月内**不再接受申请。
- 因管理体系问题不予受理的，**6 个月后**才能再次提交。

> 注：以上时限在 CNAS-RL10 正式版中可能调整，交付前核对 CNAS 官网现行文本。

## 三、现场评审准备

### 1. 文件归档

- 四级文件受控版本齐全、发放回收记录清楚、作废文件隔离。
- 记录按样本编号/日期可快速检索；准备评审组抽查用的样本全生命周期档案包（采集→接收→制备→储存→质控→分发）。
- 条款对照表（差距分析报告）与整改闭环证据单独成册。

### 2. 现场布置

- 储存区：冰箱/液氮罐标识、温度显示与 24h 监控、报警装置、备用电源与备用存储空间、样本位置映射图。
- 分区：接收区、处理区、储存区、档案区标识清晰；清洁与生物安全条件匹配样本风险等级。
- 设备：校准标签在有效期内，台账与实物一一对应。

### 3. 人员应答演练

- 关键岗位（负责人、技术主管、质量主管、样本操作岗、内审员、授权签字人）熟悉本岗位职责与相关 SOP。
- 常见提问：样本如何唯一标识、温度报警怎么处置、冻融次数怎么控制、不符合样本怎么处置、内审发现了什么问题、管评做了什么决议、外部运输商怎么评价、知情同意版本怎么管。
- 应答原则：如实回答、指向记录、不编造；不知道的记下来查证后补交。

### 4. 模拟评审

用 `assets/评审前核查清单.md` 逐项打勾，重点抽查：

- 随机挑 3-5 份样本，走完整溯源链，核对记录一致性。
- 随机挑 1 台设备，核对台账、校准、维护、温度记录。
- 随机挑 1 名人员，核对培训、能力评估、上岗授权、保密承诺。
- 抽查内审不符合项从开具到关闭的完整证据链。
- 抽查伦理批件与知情同意书覆盖申请范围的情况。

## 四、高频不符合项清单（现场评审）

| 类别 | 典型不符合 | 依据条款 |
|---|---|---|
| 可追溯性 | 样本无唯一标识、溯源链断点、电子记录无权限分级/无备份 | 7.5、7.10 |
| 温度与设备 | 无 24h 连续监控、报警无处置记录、无备用电源/灾难恢复、校准证书未确认 | 6.5、7.7、8.5 |
| 外部供方 | 冷链运输商/校准服务商未评价、未再评价、合同无质量要求 | 6.4 |
| 文件与记录 | SOP 与实际不一致、无版本控制、记录事后补写、空库/纸面体系 | 8.2、8.3、8.4 |
| 内审管评 | 内审未覆盖全部条款、无真实不符合项、管评无输入清单/无决议跟踪 | 8.8、8.9 |
| 人员 | 岗位职责不清、无培训考核、无上岗授权、内审员不独立 | 5.9、6.2 |
| 方法与技术经历 | 方法未确认/验证、申请范围项目无真实经历记录 | 7.9、申请条件（八） |
| 不符合与投诉 | 不符合输出无处置、纠正措施无有效性验证、投诉无闭环 | 7.11、7.13、8.7 |
| 伦理与隐私 | 伦理批件过期/未覆盖、知情同意版本不清、样本去向与同意范围不一致 | 4.1.6、4.3 |
| 公正性保密性 | 无公正性风险识别、无保密承诺、数据访问权限过宽 | 4.2、4.3 |

## 五、不符合项整改闭环（CAPA）

每项不符合项按四段写，写清「怎么证明已做到」：

1. **根本原因**：不是「人员疏忽」这类表面原因，追到流程/文件/资源/培训层面。
2. **纠正措施**：立即处置已发生的问题（如补齐记录、隔离不符合样本、重新校准）。
3. **预防措施**：改文件、改流程、加监控、加培训，防止再发生。
4. **验证方法**：谁来验证、验证什么记录、多久后复核有效性。

证据链：不符合项报告 → 原因分析 → 整改计划 → 实施记录 → 有效性验证 → 关闭批准。

整改报告模板见 `assets/整改跟踪表模板.md`。

## 六、获证后持续改进

- 监督评审准备：保持体系持续运行、记录不断档、内审与管评按周期开展。
- 扩项认可：新增样本类型或活动须先做方法确认/验证、积累真实经历记录、更新范围文件。
- 变更管理：人员、设备、场所、范围、法规变更须评估影响并留记录。
- 法规换版：CNAS-RL10 正式版、人遗新规等发布后及时复核体系文件与口径。
