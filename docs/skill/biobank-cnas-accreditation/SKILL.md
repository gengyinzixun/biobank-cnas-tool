# 生物样本库 CNAS 认可咨询（中国口径）

## 定位与边界

本技能把「生物样本库 CNAS 认可」咨询能力固化为可复用的中国口径知识包：以 CNAS 官网公布的申请条件、CNAS-CL10:2020（等同采用 GB/T 37864-2019 / ISO 20387:2018）、CNAS-RL10 / RL02 / AL21 及人源样本相关国家法规为唯一依据，输出可直接交客户的核查清单、差距分析报告、整改路线图、SOP 骨架与条款解读。

边界（必须向客户声明）：

- 只判断「是否具备申请资格」与「如何准备」，不判断「能否通过评审」，不替代 CNAS 官方受理与评定决定。
- 适用科研用生物样本保藏。临床诊断/治疗用材料走 ISO 15189 医学实验室认可路径，混合场景须在申请范围中明确区分。
- 涉及人类遗传资源行政许可的，仅做合规提示与路径引导，正式申报判断交由「人遗申报备案评估工具」。
- 结论为初步评估，不构成法律意见或认证结论。

## 何时使用

触发场景：认可申请条件咨询、8 项门槛核对、体系文件（质量手册/程序文件/SOP/记录）搭建、内审与管理评审、能力验证 RL02、量值溯源、样本全生命周期可追溯、现场评审准备、高频不符合项整改、伦理审查与知情同意、人遗保藏许可、条款号查询、差距分析表与核查清单出具。

不触发：纯生物信息学数据分析（UK Biobank、GWAS、组学流程）、临床检验报告解读、ISO 15189 医学实验室认可全流程、ISO 9001 通用体系、国外 CAP/ISBER/CLIA/GDPR 体系落地（仅可作为术语参考，不得作为中国口径依据）。

## 口径红线（先置，最高优先级）

1. **准则编号**：中国生物样本库认可准则是 **CNAS-CL10:2020**，不是 CNAS-CL06。CNAS-RL02 是《能力验证规则》，不是「能力认可准则在生物样本库领域的应用说明」。任何沿用旧资料的误标须纠正后再答复。
2. **条款号**：内审是 **GB/T 37864 第 8.8 条**、管理评审是 **第 8.9 条**。网传自查表把它们标成 4.7 / 4.8，与国标原文不符，禁止照抄。章节结构见 `references/01-basis.md`。
3. **依据优先级**：法规/准则明文（置信度 A）> 官方解答口径（B）> 实践惯例（C）。实践惯例必须显式标注，并提示「重大事项与 CNAS 或专业顾问确认」。
4. **禁止编造**：不得凭记忆给出法规条号、文件编号、版本号、收费金额。引用前查 `references/01-basis.md`；无法确认时写「以 CNAS 官网最新发布为准」。
5. **区分机构类型**：医院附属样本库、科研院所样本库、独立运营样本库的法律地位、伦理归口、人遗合规路径不同，先问清再给方案。
6. **区分强制与推荐**：准则中「应/shall」为强制，「宜/should」为推荐，整改资源按此排序。
7. **给出证据要求**：整改方案除「做什么」，必须写「怎么证明已做到」（记录、台账、报告、批件、验证报告）。
8. **换版纪律**：CNAS-RL10 有 2025 修订征求意见稿，正式版发布后须复核流程时限；人遗《实施细则》已于 2026-11-11 换版为卫健委令第 16 号。交付前核对现行文本。

## 工作流程（7 阶段，与认可咨询 SOP 对齐）

按 `references/03-workflow.md` 执行，阶段概要：

1. **需求诊断** — 问清机构类型、样本来源（人源/非人源）、申请范围、现有基础、目标时间节点、主要痛点。使用 `references/05-intake.md` 的访谈提纲。
2. **资格快判** — 用 `scripts/eligibility_check.py` 或 `references/02-eligibility.md` 核对 8 项硬门槛 + 人源红线，输出「可申请 / 补正后可申请 / 暂不具备」三档结论。
3. **差距分析** — 按 CNAS-CL10 第 4-8 章逐条对照，输出条款对照表（符合 / 部分符合 / 不符合 + 证据要求）。方法见 `references/04-gap-analysis.md`。
4. **整改路线图** — 按 P0（阻断项与红线）→ P1（硬门槛与高频不符合项）→ P2（一般项）排序，明确责任人与时限。
5. **文件体系建设** — 搭建四级文件（质量手册 / 程序文件 / SOP / 记录表单），模板见 `assets/`。SOP 按「目的、范围、职责、程序、相关文件、记录」六段起草。
6. **内审与管理评审辅导** — 内审覆盖全部范围与条款、不符合项闭环；管评输入/输出齐全。按 8.8 / 8.9，见 `references/04-gap-analysis.md`。
7. **评审前预检与持续改进** — 模拟评审、现场核查清单、人员应答；获证后监督评审、扩项、不符合项关闭。见 `references/06-onsite.md`。

## 申请资格快判（8 项硬门槛 + 人源红线）

CNAS 官网申请条件逐条映射为 8 项硬门槛，完整判定逻辑与题库见 `references/02-eligibility.md`：

| # | 门槛 | 优先级 |
|---|---|---|
| ① | 明确的法律地位（独立法人或法人授权部门） | P0 |
| ② | 有效的自我评估（覆盖准则 4-8 章并形成书面报告） | P1 |
| ③ | 管理体系正式、有效运行 ≥6 个月且有完整记录 | P0 |
| ④ | 完整内审（8.8）+ 管理评审（8.9）+ 全要素运行记录 | P0 |
| ⑤ | 能力验证满足 CNAS-RL02 | P1 |
| ⑥ | 足够资源与授权签字人资格（5.9、6.2） | P1 |
| ⑦ | 仪器设备量值溯源（6.5、7.7） | P1 |
| ⑧ | 技术经历覆盖全部申请项目/参数（5.7、7.9） | P1 |

人源样本追加 3 条红线（任一不通过即「暂不具备」）：伦理审查批件、知情同意、人类遗传资源保藏许可/备案。非人源样本不适用。见 `references/07-hgr-redline.md`。

三档结论：存在红线或核心门槛（①③④）未满足 → **暂不具备**；无阻断但有待补正项 → **补正后可申请**；全部满足 → **可申请**。
